
# Excel Data Cleaner 🧹

A beginner-friendly Python project that cleans Excel data using Pandas.

## Features
- Removes duplicate rows
- Cleans extra spaces
- Standardizes column names
- Removes completely empty rows
- Converts dates into a consistent format
- Exports cleaned data to Excel and CSV

## Technologies
- Python
- Pandas
- OpenPyXL

## How to Run

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Run the program:

```bash
python automation.py
```

The program generates sample Excel data and exports cleaned Excel and CSV files.

## Learning Goals
This project demonstrates Python file handling, data cleaning, and Excel automation.
